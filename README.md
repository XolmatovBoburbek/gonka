# 🌸 Sakura Drift — аниме-гонки

Браузерная 3D-гонка в аниме-стиле с видом от третьего лица: 8 чиби-гонщиков, боты,
дрифт с буст-шкалой на три уровня, предметы и три красивые локации. Вся графика, модели и музыка
генерируются кодом — никаких внешних ассетов.

## Как запустить

```bash
npm install
npm run dev          # http://localhost:5173
```

Сборка:

```bash
npm run build        # dist/ — обычная сборка для хостинга
npm run build:single # dist-single/index.html — вся игра в одном файле, открывается без сервера
```

Нужен браузер с WebGL 2 (Chrome, Edge, Firefox, Safari). Работает и на телефоне — появятся
экранные кнопки, газ включается автоматически.

## Что есть в игре

- **8 гонщиков** — Сакура, Рэн, Юки, Кайто, Хана, Акира, Нэко, Рю. У каждого своё лицо,
  причёска, эмоции (моргают, радуются, морщатся от попаданий) и характеристики
  (скорость / ускорение / управление).
- **3 локации**
  - **Сакура-Долина** — солнечный день, цветущие сакуры, тоннель из тории, красные мосты
    над рекой, пагода у шпильки, бамбуковая роща и Фудзи на горизонте.
  - **Неон-Токио** — ночной город, неоновые вывески, небоскрёбы, эстакада-«восьмёрка».
  - **Закатный Берег** — золотой закат над океаном, пальмы, маяк на утёсе и пирс.
- **Ускорения**
  - дрифт с настоящим углом заноса: руль в поворот — круче, контр-руль — выравнивание,
    долгий контр-руль перекладывает занос в другую сторону; занос немного гасит скорость;
  - буст-шкала из трёх делений копится в заносе (и на трюках); `F` тратит все полные деления
    сразу — буст 1 (синий), 2 (оранжевый) или 3 уровня (фиолетовый, самый сильный и долгий);
  - бустеры-шевроны на дороге;
  - трамплины с трюками (дрифт в воздухе → ускорение при приземлении);
  - ракетный старт (газ за мгновение до «СТАРТ!»).
- **Предметы** из радужных кристаллов:
  - 🔥 **Турбо** — мощный рывок вперёд;
  - 🌟 **Звёздная сфера** — самонаводится на соперника впереди и закручивает его;
  - 🛡️ **Барьер** — щит от одного попадания;
  - 🧊 **Ледяная ловушка** — остаётся позади и замораживает того, кто наедет.
  Отстающим чаще выпадают атакующие предметы, лидерам — защитные.
- **Боты** ведут гоночную траекторию, тормозят перед поворотами, дрифтуют, объезжают
  ловушки, охотятся за кристаллами и тактически применяют предметы. Три уровня сложности.
- Интро-облёт трассы, отсчёт со стартовыми огнями, миникарта, таблица результатов,
  пауза, настройки графики и звука.
- **Графика «Авто»** (по умолчанию): стартовый уровень подбирается по видеокарте, затем
  качество само подстраивается под FPS (разрешение, сглаживание, bloom, тени) — без
  перекомпиляции шейдеров и рывков.
- Аниме-эффекты: cel-shading, чернильные контуры, bloom, манга-линии скорости,
  надписи «БАХ!», «ДЗЫНЬ!», «ТУРБО!», конфетти на финише.
- Процедурная музыка и звуки на Web Audio, у каждой локации своя тема: вафу-рок с кото, сямисэном,
  флейтой синобуэ и тайко на японском ладу (Сакура-Долина), евробит с суперсо-лидом, медью и октавным
  басом (Неон-Токио), тропический грув со стил-пэном, укулеле, конгами и бонго (Закатный Берег).

## Управление

| Клавиши | Действие |
| --- | --- |
| `↑` / `W` | газ |
| `↓` / `S` | тормоз, задний ход |
| `←` `→` / `A` `D` | руль |
| `Shift` / `Пробел` | прыжок и дрифт (держать в повороте — копится буст-шкала), трюк на трамплине |
| `F` / `X` | буст: потратить накопленную шкалу (1–3 уровень) |
| `E` / `Enter` | использовать предмет |
| `C` | посмотреть назад |
| `R` | вернуться на трассу |
| `Esc` / `P` | пауза |
| `M` | звук вкл/выкл |

Геймпад: стик/крестовина — руль, RT/A — газ, LT/B — тормоз, RB/X — дрифт, Y — буст, LB — предмет, Start — пауза.

## Устройство проекта

```
src/
  main.js, game.js       — запуск и главный цикл: меню → выбор → гонка → результаты
  core/                  — рендер и пост-эффекты, управление, процедурный звук
  world/                 — cel-shading и контуры, небо, трасса-сплайн, рельеф, вода,
                           частицы, библиотека декораций
  race/                  — физика карта, модели пилотов, ИИ, предметы, камера, логика гонки
  tracks/                — локации (разметка трассы + окружение), реестр с ленивой загрузкой
  ui/                    — меню, HUD с миникартой, иконки, стили
  data/characters.js     — персонажи и их характеристики
```

Трасса — замкнутый сплайн с равномерными сэмплами; физика картов работает «в пространстве
трассы» (проекция на осевую линию, стены, бездорожье, эстакады). Параметры отладки в адресе:
`?quality=auto|low|medium|high` (фиксированный пресет отключает автонастройку), `?autostart&track=neon&char=yuki`, `&autopilot`, `&skipintro`.
