# Sakura Drift для Roblox

Порт веб-игры на Roblox (Luau). Механика та же, что в браузерной версии:
- дрифт с настоящим углом заноса;
- буст-шкала из трёх делений;
- бусты складываются;
- старт на оборотах с зелёной зоной;
- монеты, слипстрим, трамплины и трюки;
- четыре трассы, предметы, боты.

Физика карта и ИИ ботов перенесены один в один и проверены против веб-версии: расхождение траектории за гонку не больше 4 мм.

## Как это устроено

Игра — онлайн-гонки игроков друг против друга, до 8 машин на сервере.

- **Заезды между игроками.** В лобби все голосуют за одну из четырёх трасс: Сакура-Долина, Неон-Сити, Закатный берег, Момидзи. Если проголосовали все, старт ускоряется. После финиша показываются итоги, и все возвращаются в лобби.
- **Кубки и монеты.** В заезде с двумя и более игроками разыгрываются кубки рейтинга: первому +30, последнему −15, остальным между ними. Кубки и победы видны в списке игроков Роблокса. Монеты дают за место и за собранное на трассе.
- **Боты только для одиночки.** Если на сервере два и больше игроков, ботов нет. Если игрок один, ему добавляются 5 ботов, чтобы было с кем ехать; кубки в таком заезде не разыгрываются. Настраивается в `Config.lua`: `BOTS_SOLO`, `BOTS_PVP`, `MIN_PLAYERS`.
- **Гараж с машинами.** Восемь машин с разными кузовами и характеристиками: купе, спорткар, малолитражка, маслкар бесплатно; багги 250, дрифт-кар 450, пикап 700, болид 1000 монет. Цвет кузова выбирается из десяти красок. Прогресс хранится в DataStore.
- **Своя машина считается у игрока.** Это модуль `Shared/Kart`, та же физика, что в браузере, поэтому управление отзывчивое без задержки сети. Клиент шлёт состояние серверу 20 раз в секунду.
- **Сервер** ведёт кристаллы и предметы, монеты, круги, места и награды. Круг засчитывается, только если прогресс честно перескочил линию.
- **Предметы:** Турбо, Звёздная сфера (самонаводится на соперника впереди), Барьер, Ледяная ловушка. Лидерам чаще выпадает защита, отстающим — атака.
- **Монеты на трассе** дают +1% к скорости за каждую в запасе (максимум 10). При попадании теряется 3.
- **Трасса строится на клиенте** из тех же данных, что физика: дорога, бордюры, стены, бустеры, трамплины, арки, трибуна, насыпь из Terrain, опоры мостов, декор, облака и освещение под тему трассы.

```
roblox/
  default.project.json   проект Rojo
  SakuraDrift.rbxlx      готовое место — открыть в Roblox Studio
  src/shared/            → ReplicatedStorage.Shared: Kart, Bot, Track, TrackData, Tracks, Layout, Net, Config, Cars
  src/server/            → ServerScriptService: Main (заезды), Profiles (DataStore), ErrorRelay (диагностика)
  src/client/            → StarterPlayerScripts: Main, Boot (экран загрузки), World, KartModel, Hud, Input, Audio
  assets/audio/          музыка и звуки для загрузки в Roblox (manifest.json — что куда)
  tests/                 прогон Luau вне Roblox (Node + luau-web)
```

## Как опубликовать

1. Откройте `roblox/SakuraDrift.rbxlx` в **Roblox Studio** (File → Open from File).
2. Нажмите **Play**, чтобы проверить локально. Чтобы проверить мультиплеер, откройте вкладку Test → Clients and Servers → 2 Players → Start.
3. Опубликуйте: **File → Publish to Roblox**, создайте новый опыт и дайте ему название.
4. Откройте **Game Settings**:
   - **Security** → включите **Enable Studio Access to API Services**. Это нужно, чтобы кошелёк и машины сохранялись. На опубликованном сервере DataStore работает и без этой галочки; она нужна только для теста в Studio.
   - **Places** → **Server Fill** / **Max Players**: поставьте **8**. На сервере 8 картов, лишние игроки станут зрителями.
   - **Permissions** → **Public**, когда будете готовы открыть игру.
5. На странице опыта в Creator Hub загрузите иконку и превью.

Если измените код, пересоберите место:

```bash
cd roblox
rojo build default.project.json -o SakuraDrift.rbxlx
```

Можно работать и вживую: запустите `rojo serve` и подключитесь плагином Rojo в Studio.

## Звук

Roblox не умеет синтезировать звук на лету, как браузерная версия, поэтому музыка, мотор и эффекты записаны в файлы в `roblox/assets/audio/`.

1. В Creator Hub откройте **Creations → Development Items → Audio → Upload Asset** (или **Asset Manager → Bulk Import** в Studio). Загрузите файлы.
2. Скопируйте ID каждого звука (`rbxassetid://…`) в `src/shared/Config.lua`, в таблицу `Config.Sounds`. Какой файл к какому ключу относится, записано в `assets/audio/manifest.json` (поле `configKey`).
3. Пересоберите место или вставьте ID прямо в модуль `ReplicatedStorage.Shared.Config` в Studio.

Пока ID пустые, игра работает без звука. Всего 50 файлов (около 6 МБ, OGG):
- 6 тем музыки и 4 версии финального круга;
- 3 петли мотора;
- визг дрифта и шум буста;
- 35 звуковых эффектов.

Все петли сделаны бесшовными. Высота тона мотора считается из оборотов, как в браузере. Для этого в `Config.Sounds.engineLoopHz` и соседних полях указана частота вспышек в записанной петле; она уже заполнена из манифеста.

## Управление

| | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Руль | ← → / A D | левый стик, крестовина | ◀ ▶ |
| Газ | ↑ / W | R2 | ГАЗ |
| Тормоз / назад | ↓ / S | L2 | ТОРМ |
| Дрифт, трюк в прыжке | Пробел / Shift | R1 / X | ДРИФТ |
| Буст из шкалы | F / X | Y | ⚡ |
| Предмет | E / Q / Enter | L1 | ✦ |

На светофоре держите газ так, чтобы стрелка стояла в зелёной зоне: получите рывок на старте. Если перегазовать в красную зону, карт закрутит.

## Настройки

Всё в `src/shared/Config.lua`:
- боты: сложность, сколько их в одиночном и в онлайн-заезде;
- число кругов и список трасс;
- длительность лобби и итогов;
- награды монетами и кубками;
- имя DataStore;
- ID звуков.

Машины и краски — в `src/shared/Cars.lua`.

## Тесты

Код на Luau прогоняется вне Roblox в Node через `luau-web`:

```bash
node tests/compile.mjs                    # синтаксис всех модулей
node tests/run.mjs tests/physics_test.lua  # физика против эталона из веб-версии (tests/compare.mjs)
node tests/run.mjs tests/bots_test.lua     # 8 ботов × 4 трассы × 3 сложности — все финишируют
node tests/run.mjs tests/net_test.lua      # упаковка сети, расстановка монет и кристаллов
node tests/run.mjs tests/game_test.lua     # сервер + клиент на заглушках Roblox: два заезда подряд
```

Перед запуском тестов нужен `luau-web`: `npm i luau-web` в любой папке; путь к нему указан в `tests/run.mjs`.
